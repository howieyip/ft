创建一个空目录，例如E:\FT
1.下载富途OpenD客户端并安装运行，下载地址：https://www.futunn.com/download/openAPI

2.下载富途openAPI代码并解压到E:\FT，得到E:\FT\py-futu-api-master，下载地址：https://github.com/FutunnOpen/py-futu-api
进入py-futu-api-master\futu\examples目录，把我提供的fight.py和logger.py复制到这个目录中，并在此创建一个空目录logs，用来保存日志
3.下载代码运行环境并安装，注意有一步要勾上添加环境变量，下载地址：https://www.anaconda.com/distribution/

4.下载代码运行软件并安装，下载地址：https://www.jetbrains.com/pycharm/download
打开pycharm，选择菜单File -> New Project，选择Location为E:\FT\py-futu-api-master，然后确认创建
在左侧的目录树中双击fight.py文件，右侧就会打开这个文件的代码，代码开头有一段：
# 运行前需检查并改变下面的值
TRADE_ENV = ft.TrdEnv.REAL                          # 实盘交易：REAL，模拟交易：SIMULATE
UNLOCK_PASSWORD = '123456'                          # 解锁交易密码，实盘交易必须设置
ALLOW_RETRACE = 2000                                # 今日盈亏允许回撤多少元，一旦超过就会自动清仓

改好之后，右键代码任意地方弹出菜单，选择run fight运行程序
注意，只要修改了代码，就需要重新运行程序才能生效，下方左边绿色按钮就是重新运行，红色按钮就是停止

第一次可能不会成功，因为缺少必要的配置或组件，需要安装：
右上角fight下拉选择edit configurations打开，Python interpreter那项选择一个Python 3.x的版本
缺乏google模块，命令行输入pip install protobuf，回车安装
缺乏simplejson模块，命令行输入pip install simplejson，回车安装
如果速度慢是因为安装源在国外，可以配置pip.ini文件为阿里云的国内源
[global]
index-url = http://mirrors.aliyun.com/pypi/simple/
trusted-host = mirrors.aliyun.com
